# "This Week on GitHub" — the 10 trending repos, explained

Dark Tech Keynote · ~3:05 · 1920×1080 · 24 fps · English VO (en-US neural, calm presenter) · captions burned in + `.srt`.
Facts: FACTS.md (GitHub weekly trending, fetched 2026-11-08, and each README). Accent: electric violet `#8B7CFF` — reserved for the thing each repo *does* (the typed command, the key result) and the one giant number.

## 1. Three candidate structures
- **A. Ranked list 1→10** — clear, but the strongest item is spent first and attention drops.
- **B. Countdown 10→1** — every segment raises the stakes; the classic shape for a top-10.
- **C. Grouped by theme** (agent tools / data / design) — smarter, but loses the ranking viewers came for.
**Chosen: B**, with one interruption: at #7 the film stops for the one giant number, **+17,100 stars this week** (the most of the ten), on its own screen.

## 2. Logline and arc
Ten repos in three minutes: each one's card drops onto a dark stage, a command types itself, and one line says why it matters. Setup: the trending board lights up line by line (10 rows). Each segment: card → usage → benefit. Ending: the board again, all ten lit, "Pick one. Try it this weekend."

## 3. Benchmark
Software launch keynotes (black stage, one line per screen, snap-grid UI, the lone giant number) — learn pacing and restraint; copy no interface, font, logo or melody.

## 4. Segment grammar (the same three beats for every repo, so the viewer learns it once)
| Beat | Picture | VO |
|---|---|---|
| WHAT | the repo card drops in (rank numeral, owner/name, language dot, total stars, "+N this week" counting up) | "Number N. X, a …" |
| HOW | a terminal panel slides in; the real command from the README types itself in the accent (or, for an app, its platforms) | how you use it |
| WHY | a benefit tile pops beside it with a check glyph | "The benefit: …" |
Transition: whip pull-out to the board (the next row lights) on a downbeat, then push in.

## 5. Camera
Locked close on the card (WHAT), pan right to the terminal (HOW), pull back to frame card + terminal + benefit (WHY), whip out to the board between repos; the #7 giant number gets a push-in through a frozen frame.

## 6. Sound
Process-music bed (Reich-like phasing marimba-ish FM plucks + soft pulse), 116 BPM, one designed UI sound family: card drop thock, key ticks while typing, a soft confirm chime on each benefit, a whoosh on each whip; near-silence before the giant number. Music ducked under voice.

## 7. Type
Inter (UI, captions), Inter Tight 600 for the giant number, JetBrains Mono for commands and labels (all OFL). Captions: bottom-centre toast with an accent "speaking" dot. Typed commands are not repeated in captions.
